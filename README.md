# 📱 WhatsApp Link Generator

A simple, fast, and secure web tool to generate official WhatsApp click-to-chat links (`https://wa.me`). Built strictly following the official WhatsApp API guidelines.

🔗 **[Live Demo](https://askara25.github.io/whatsapp_link_generator/)**

## ✨ Features
* 🔒 **100% Client-Side:** No data is sent to a server. Your phone numbers remain completely private.
* 💬 **Pre-filled Messages:** Supports spaces and special characters by automatically URL-encoding your text.
* 📱 **Fully Responsive:** Works perfectly on both desktop and mobile browsers.
* 🚀 **Zero Dependencies:** Built with pure HTML, CSS, and Vanilla JavaScript.

## 🛠️ How It Works
The tool structures the input based on the official WhatsApp guidelines:
`https://wa.me<number>?text=<encoded_message>`

## 🚀 How to Run Locally
1. Clone the repository: `git clone https://github.com`
2. Open `index.html` in any browser.
